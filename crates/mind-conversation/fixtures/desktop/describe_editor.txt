  act: new()  [standard, settles on return]
       Open an empty new tab and make it the active one. Nothing is written to disk until `save_as` gives it a path; up to eight tabs can be open.
  act: open(path)  [standard, settles on return]
       Open the UTF-8 text file at this path in a tab and make it active; a file already open is brought forward instead of opened twice. The file is not changed.
         path: string — Absolute path to the file, or one starting `~/`. Up to 1 MiB of UTF-8 text; a binary or larger file is refused and nothing is opened.
  act: save()  [standard, settles on return]
       Write the active tab back to the file it was opened from and check the bytes on disk. A tab with no file is refused — give `save_as` a path. When the editor is asking about unsaved changes, this is the answer that writes the tab and closes it.
  act: save_as(path)  [standard, settles on return]
       Write the active tab to this path and keep the tab on it from now on. It refuses rather than overwrite a file that already exists.
         path: string — Absolute path of the file to write, or one starting `~/`. Its folder must exist and nothing may already be at that path.
  act: show()  [standard, settles on return]
       Bring the Editor window to the front. Nothing in any tab is read or changed.
  act: close()  [standard, settles on return]
       Close the active tab. A tab with unsaved changes is not closed: the window asks, and `save`, `discard` or `cancel` answers it. The last tab closed leaves an empty one.
  act: cancel()  [standard, settles on return]
       Dismiss whichever dialog is open and leave every tab exactly as it was. Nothing is closed, saved or discarded.
  act: discard()  [sensitive, settles on return]
       Throw away the unsaved changes in the tab the window is asking about and close it. The text that was never saved is gone and cannot be recovered.
  act: find(text)  [standard, settles on return]

         text: string — The text to look for, matched literally. Case is ignored unless the find bar's match-case box is ticked; an empty query clears the matches.
  act: find-next()  [standard, settles on return]

  act: find-prev()  [standard, settles on return]

  act: replace()  [standard, settles on return]
