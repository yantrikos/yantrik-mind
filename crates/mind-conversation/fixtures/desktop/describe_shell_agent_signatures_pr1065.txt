(action signatures only: this answer holds no state)
  act: agent_run(command, cwd?, wait?)  [sensitive, settles later]
       Run one command line in a fresh terminal of your own, in your pane — not the person's Terminal. Its output is also shown live in a terminal in Mind View, your desk; `shown_in` in the answer says whether it was. Answers when it exits, with `exit_code` (or `signal`), `cwd_after` and the `tail` of its output; if it is still going after `wait` seconds it answers `running: true` with a `job` id. The directory carries to your next command; exported variables and other shell state do not. The environment is HOME, USER, PATH, LANG and TERM only. Acts for the agent named by the agent token your call carries beside `args` (`yos act --agent-token`, or YANTRIK_AGENT_TOKEN in yos's environment) — never an argument. What it runs can do anything you can.
         command: string — One command line, as it would be typed. Pipes, redirection, `&&` and `cd` work; it runs under bash
         cwd?: string — Where to run it, absolute or relative to your current directory. Left out: where your last command ended
         wait?: number — A number of seconds, e.g. 30, not true or false. How long to wait for it to finish before answering `running: true`. Default 120, at most 600
  act: agent_job(job, wait?)  [standard, settles on return]
       Wait for one of your commands that answered `running: true`, and say where it stands: the same answer `agent_run` gives. `wait` is a number of seconds, and `wait: 0` only looks. Answers early if the command starts waiting for input. Acts for the agent named by the agent token your call carries beside `args` (`yos act --agent-token`, or YANTRIK_AGENT_TOKEN in yos's environment) — never an argument.
         job: string — The `job` id `agent_run` answered with
         wait?: number — A number of seconds, e.g. 30, not true or false. How long to wait for it to finish. Default 120, at most 600
  act: agent_input(job, text)  [sensitive, settles on return]
       Type into one of your running commands, exactly the characters given — no newline is added, so end with \n to press Return; \u0003 is Ctrl-C. Answers with where the command stands a moment later. Acts for the agent named by the agent token your call carries beside `args` (`yos act --agent-token`, or YANTRIK_AGENT_TOKEN in yos's environment) — never an argument. What it runs can do anything you can.
         job: string — The `job` id `agent_run` answered with
         text: string — The exact characters to send, up to 64 KiB
  act: agent_kill(job)  [standard, settles on return]
       Stop one of your commands: its whole process group gets SIGTERM, and SIGKILL two seconds later if anything is left. Answers once it has ended, with how. Acts for the agent named by the agent token your call carries beside `args` (`yos act --agent-token`, or YANTRIK_AGENT_TOKEN in yos's environment) — never an argument.
         job: string — The `job` id `agent_run` answered with
